## 🔗 Integration Examples

### Example 1: Quick Integration
```python
import json

# Load parameters
with open('optimized_results/optimized_params_20240218_143022.json') as f:
    config = json.load(f)
    params = config['best_parameters']

# Use with your signal generator
from signal_optimizer import SignalGeneratorWrapper
import pandas as pd

df = pd.read_csv('market_data.csv')
signal_gen = SignalGeneratorWrapper(df)
df_signals = signal_gen.generate_signals(params)

# Filter buy signals
buy_signals = df_signals[df_signals['Signal'] == 1]
print(f"Generated {len(buy_signals)} buy signals")
```

### Example 2: Import Python File
```python
# Import optimized parameters
from optimized_results.optimized_params_20240218_143022 import (
    OPTIMIZED_PARAMS,
    BEST_METRICS
)

print(f"Expected accuracy: {BEST_METRICS['accuracy']:.1%}")
print(f"Expected signals: {BEST_METRICS['n_signals']}")

# Use parameters
my_strategy = TradingStrategy(OPTIMIZED_PARAMS)
```

### Example 3: Re-evaluation
```python
from signal_optimizer import (
    SignalGeneratorWrapper,
    LightGBMEvaluator
)
import json

# Load parameters
with open('optimized_results/optimized_params_20240218_143022.json') as f:
    params = json.load(f)['best_parameters']

# Test on new data
new_data = pd.read_csv('latest_market_data.csv')
signal_gen = SignalGeneratorWrapper(new_data)
df_signals = signal_gen.generate_signals(params)

# Evaluate
evaluator = LightGBMEvaluator()
results = evaluator.evaluate(df_signals)

print(f"Performance on new data:")
print(f"  Accuracy: {results['metrics']['accuracy']:.1%}")
print(f"  F1-Score: {results['metrics']['f1_score']:.1%}")
print(f"  Signals: {results['n_signals']}")
```
